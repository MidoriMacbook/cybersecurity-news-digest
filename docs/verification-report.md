# Отчёт проверок

Дата: 15 октября 2026. За основу принят предоставленный архив; старой Git-истории в новой рабочей копии нет.

## Очистка

В публичный проект не перенесены локальная SQLite-база, .env.local, вложенные архивы, результаты личных запусков, внутренние отчёты и инструкции, служебные планы и ранее собранные файлы. Сохранены исходники, тесты, синтетические наборы, инструкции запуска и конфигурация публикации. Поиск шаблонов ключей не обнаружил совпадений в принятом исходном архиве. Локальный файл окружения содержал только адрес API; он исключён из публичной копии.

## Подтверждённые проверки

- Исходная версия: 63 backend-теста, Ruff и mypy прошли.
- Четыре добавленных регрессионных теста первоначально воспроизвели ошибки: отрицание затронутости системы, смешение исследователя с пострадавшей организацией, дата окончания поддержки как дата события, необработанная ошибка хранилища.
- После исправлений: 67 backend-тестов прошли. Ошибка хранилища возвращает безопасный HTTP 503 без connection string.
- Реальные платные запросы без ключа не выполнялись. В тестах используются имитированные ответы модели.
- Frontend-команды CI выполняются в apps/web, где находится packageManager. Docker получает pnpm-workspace.yaml до установки зависимостей.

Есть предупреждение устаревания интерфейса Starlette TestClient с httpx; оно не является провалом тестов.

## Практические ограничения

Текст остаётся экстрактивным. Сопоставление цитаты с источником не устанавливает истинность новости или подлинность загруженных метаданных. Группировка и обнаружение противоречий консервативны; неизвестные роли и даты остаются пустыми. Автоматического перевода нет. Внешняя PostgreSQL и платный API модели пока не проверялись. Письмо является предпросмотром; автоматической отправки нет.
