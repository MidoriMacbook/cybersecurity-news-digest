# Оценка качества и отчёт проверок

Критерии: точная граница периода, отсутствие выдуманных фактов, provenance каждого fragment, корректное объединение, сохранение противоречий/оговорок, единый набор событий и ссылок для письма и поста, лимиты 4000/2000 без URL, безопасные запросы и экспорт.

Автоматический набор включает синтетические кейсы, а не реальную независимую оценку журналистской достоверности. Regression tests показывают поведение на проверенных входах; они не доказывают полноту определения всех ИБ-тем или всех смысловых противоречий.

Фактические команды, результаты, browser flow и состояние публикации будут добавлены по завершении прогона в docs/verification-report.md. До появления подтверждённого отчёта CI/Docker/public deployment считаются конфигурацией, а не выполненной проверкой.
