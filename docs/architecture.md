# Архитектура

Next.js создаёт статический интерфейс; API исполняется только в Python. Это позволяет публиковать web отдельно на Vercel или обслуживать его из того же FastAPI-процесса. Next.js server routes отсутствуют намеренно: бизнес-логика и health находятся в FastAPI, а static export не поддерживает серверные маршруты.

Обработка состоит из независимых сервисов: ingestion → date filter → relevance → extraction → grouping → ranking → digest/email/post → validation/journal. Domain/Pydantic модели задают строгие контракты, providers изолируют LLM, внешние источники и SQL-хранилище. Изменение поставщика модели не должно изменять границы периода или источник фактов.

Исходная запись сохраняется отдельно от нормализованной. Отсутствующие поля не достраиваются. Ссылка, источник, достаточно полный текст и timezone-aware дата необходимы для проверяемого результата. Период строго `(control_time - 24 hours, control_time]`, а не календарные «сегодня/вчера».

В mock-режиме факты извлекаются экстрактивно. LLM может предлагать фрагменты, но сервер проверяет их присутствие в исходном тексте; свободно придуманные утверждения не проходят. Это уменьшает риск галлюцинаций, однако источник сам может ошибаться. Дата в загруженном наборе остаётся заявлением отправителя, а не независимой проверкой на веб-сайте.

Группировка использует идентификаторы уязвимостей и сходство значимых признаков. Разные CVE не объединяются из-за общего заголовка. Перепечатки одного текста не повышают независимое подтверждение. Эвристики не дают гарантии полноты: итог требует просмотра журнала и подтверждающих фрагментов.

SQLAlchemy сохраняет входы, результаты, журналы и метаданные модели. DATABASE_URL переключает SQLite на PostgreSQL. На бесплатном хостинге SQLite непостоянен; экспортируйте результат или подключите внешнюю базу. Интерфейс сохраняет текущий результат в сессии браузера для удобного перехода между вкладками.

Основные границы безопасности: недоверенный текст не исполняется; пользовательские URL ограничены; iframe письма sandboxed; браузер не получает ключи; все экспортируемые данные экранируются согласно формату.
