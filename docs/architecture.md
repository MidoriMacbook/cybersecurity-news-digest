# Архитектура

Next.js/React/TypeScript экспортируют статический интерфейс. FastAPI обслуживает API и собранный интерфейс из одного Docker-контейнера. SQLAlchemy сохраняет входы, нормализованные записи, журнал и результат. SQLite используется для демонстрации; внешний PostgreSQL подключается через DATABASE_URL, отдельный сетевой прогон PostgreSQL не выполнялся.

## Порядок обработки

1. Разбор JSON/CSV/UTF-8, сохранение original_record без изменения исходных значений; нормализация отдельной копии.
2. Проверка дат и строгого периода `(control_time - 24 часа, control_time]` в Europe/Moscow.
3. Проверка релевантности и достаточности текста.
4. Извлечение безопасных фрагментов, фактов, чисел, ролей организаций и систем.
5. Объединение публикаций, выбор основного источника по эвристике качества и обнаружение противоречий. Первичное происхождение независимо не устанавливается.
6. Объяснимое ранжирование и выбор до пяти событий с учётом лимитов 4000/2000 знаков без URL.
7. Построение локальных дайджеста, письма и поста.
8. При use_ai и настроенном ключе: структурированный редакционный план → контролируемый пересказ и пост → отдельная семантическая сверка.
9. Независимые проверки цитат, ID/URL, чисел, дат, словаря, отрицаний, оговорок, сохранения содержания и итоговых форматов. При неудаче сохраняется весь локальный выпуск.
10. Сохранение результата, метаданных запуска и JSON/CSV-экспорт.

Журнал хранит source_index, original_record, normalized_record, проверки периода/темы/фактов, группу, причины решения, ошибки, предупреждения, evidence и связанные источники. Повторяющиеся ID не заменяют позицию записи и URL. Неизвестные исходные колонки остаются в original_record; HTML там хранится как данные и не исполняется.

## Режимы и воспроизводимость

Result.mode: mock — модель не вызывалась; ai — приняты все три этапа; fallback — ИИ не дал принятого выпуска. /health показывает конфигурацию, но не доказывает успешную авторизацию у поставщика. Отдельный result содержит фактическую модель и её версию, prompt_version, llm_attempts, token_usage, started_at, completed_at, application_version и журнал обращений. Неизвестные значения usage остаются null. Старые metrics сохранены для совместимости.

Наличие ключа, модель и endpoint входят в пространство кэша через безопасный fingerprint конфигурации. Сам ключ в результат не записывается. Повторный ответ из кэша возвращает исходные даты и метрики сохранённой генерации, а не выдаётся за новое обращение к модели. Изменение версии движка меняет пространство кэша.

Контролируемый пересказ ограничен перестановкой и изменением форм слов из подтверждающих фрагментов. Часть корректных синонимов не проходит консервативную проверку и вызывает fallback. Семантическая сверка вероятностная; совпадение цитат не доказывает истинность источника. Автоматического перевода и отправки почты нет.

На Render Free база и файлы контейнера непостоянны. Браузер сохраняет текущий результат в sessionStorage для переходов и reload, но это не резервная копия серверной истории.
