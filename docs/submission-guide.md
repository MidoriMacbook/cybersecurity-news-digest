# Подготовка к сдаче первого этапа

Проект создаёт выпуск по загруженному набору организаторов. Учебные входы предназначены для проверки обработки, а ссылки example.org не подтверждают реальные новости.

## Локальный запуск на Windows

Из корня проекта выполните `powershell -ExecutionPolicy Bypass -File scripts/start.ps1 -Rebuild`. Скрипт подготовит отсутствующие зависимости, соберёт интерфейс и запустит приложение по адресу http://127.0.0.1:8000. Для повторного запуска готовой сборки используйте ту же команду без `-Rebuild`. Остановка: Ctrl+C. Python 3.12 или новее, Node 22.18 или новее и pnpm должны быть установлены.

## Демонстрация

Откройте «Создать дайджест», вкладку «Демо-набор», выберите сценарий, загрузите данные и подготовьте выпуск. Проверьте дайджест, письмо, пост, источники, обоснование, журнал, проверки и метрики. Учебная контрольная дата: 14 октября 2026, 18:00 MSK. Для набора организаторов задайте их контрольное время и загрузите их JSON/CSV.

Из результата можно скачать дайджест, пост, HTML письма, полный JSON и CSV журнала. Предпросмотр письма не отправляет почту.

## Проверки и файлы для жюри

При работающем API запустите `.venv\Scripts\python.exe scripts/verify_submission.py`. Команда сохраняет восемь обязательных проверок в `artifacts/submission`: для каждой имеются input.json, result.json, verdict.json, digest.txt, post.txt, email.html и journal.csv. summary.json содержит время запуска, фактический статус, модель, версию, настройки и метрики. Там же находятся sample-result.json и три готовых формата общего демонстрационного выпуска.

Сдавайте исходный код, инструкции, промпты из apps/api/app/prompts, результаты на наборе организаторов, журналы и сведения о запуске. Архив учебных проверок не заменяет результат на контрольном наборе организаторов.

## Подключение модели

На backend задайте LLM_API_KEY, LLM_BASE_URL и LLM_MODEL, перезапустите сервер и включите «Использовать ИИ». Модель получает допустимые материалы и безопасные фрагменты, возвращает релевантность, группы, приоритет и ведущие предложения. Сервер проверяет ID, ссылки, фрагменты, границы периода, полноту групп, разные CVE и известные повторы. Редакционный план и попытки сохраняются в полном JSON. Модель не может добавлять утверждения вне проверяемых фрагментов.

При отсутствии ключа, превышении объёма или невалидном ответе используется локальная обработка с предупреждением. Токены без usage поставщика и стоимость без данных о тарификации отмечаются как недоступные. Отдельного успешного вызова внешней модели при этой доработке не было: адаптер проверен имитированными ответами, сетевой прогон требует действующего ключа.

## Ограничения перед сдачей

Текст составляется из предложений источников: это сохраняет проверяемость, но не обеспечивает полноценный пересказ своими словами. Иностранный текст не переводится автоматически. Локальные эвристики не гарантируют распознавание всех смысловых дублей и противоречий. Семантические решения ИИ требуют редакторского просмотра; проверка цитаты подтверждает её наличие, а не истинность новости. Источники и даты загруженного набора не проверяются независимо на сайте.
