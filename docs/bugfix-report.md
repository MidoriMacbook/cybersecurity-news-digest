## Принятые исправления

- `providers/editorial.py`: безопасные категории HTTP/timeout/connection/schema/grounding/invalid_response и HTTP status без exception text, URL или тела ответа; повтор получает только статическую серверную подсказку. Отклонённый текст модели не возвращается в промпт.
- `providers/storage.py`: новый AI-запрос повторяет временный fallback. Явный Idempotency-Key воспроизводит сохранённый исход, включая fallback. Старые результаты и экспорты сохраняются; одновременные сохранения с тем же ключом возвращают первый связанный исход.
- `config.py`, `schemas/models.py`: версия выполнения 1.6.1.
- `tests/test_live_regressions.py`: семь новых регрессионных случаев.
- `.dockerignore`: исключены дополнительные Python caches, bytecode и logs из контекста сборки.

Проверки фактов и семантики не ослаблены. Сохранены максимум два обращения на этап, три этапа и общий бюджет 45 секунд. Изменение кэша не является обещанием распределённой блокировки для нескольких workers; текущая демонстрация использует один экземпляр SQLite.

## Что исключено

Архив содержит 7110 файлов, включая 6435 в `.venv` и 459 в `artifacts`. Окружение, caches, bytecode, `.work`, локальная база, сырые результаты и архив не переносились в публичный репозиторий. Исходный архив и пользовательские локальные данные не удалялись. Не приняты изменения только переводов строк в CI, `.gitignore`, `.prettierignore` и Dockerfile. Некорректные CRCRLF в storage.py нормализованы.

В исходном архивном отчёте описаны прогоны старого backend 1.6: один AI-результат на событии, fallback на полном наборе и на входе с инструкцией. Это исторические сведения из архива, а не повторные проверки 1.6.1. Сообщение напарника об отсутствии доступа к публикации не описывает текущий доступ владельца.

## Свежая локальная проверка

Сначала новые тесты запущены на исходной 1.6: все семь упали по ожидаемым причинам (нет категории/подсказки, fallback возвращается из кэша, разные исходы с тем же ключом). После переноса исправлений все семь прошли.

- `pytest apps/api/tests scripts/tests -q`: 108 passed (100 backend + 8 runner).
- Ruff check и format: успешно, 50 файлов; mypy: 24 файла без ошибок.
- 18 синтетических сценариев и два расширенных формата: успешно. Ошибки провайдера здесь имитируются; это не реальный AI.
- Frontend: 30 тестов, typecheck, lint, format и production build прошли. Локальный браузер: 52 проверки пяти страниц и восьми вкладок на ширинах 375/390/768/1280, без горизонтального overflow.

Сохраняется предупреждение Starlette о будущем изменении тестового HTTP-клиента. Зависимости в рамках исправления не обновлялись.

## Публикация и проверка

Цель публикации — существующий GitHub main и существующий Render, один commit от MidoriMacbook. Зелёная CI-сборка не доказывает Render Live. Точное совпадение SHA, конечные CI jobs, health, demo, JSON/CSV, интерфейс и свежий реальный AI проверяются после push и фиксируются отдельно в release.json и артефактах проверки, без включения секретов в Git.

Исторический подтверждённый AI-прогон и границы качества: [live-ai-report.md](live-ai-report.md). Health `mode=ai` означает наличие конфигурации; конкретный результат может быть mock или fallback. Успех полного набора и фактический набор организаторов не подтверждены. Render Free засыпает; SQLite в контейнере непостоянна.
