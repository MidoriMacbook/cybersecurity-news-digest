# Кибердайджест

Сервис подготовки новостных выпусков по кибербезопасности. Отбирает до пяти событий за последние 24 часа, объединяет повторы и сохраняет ссылки на источники.

[Открыть сайт](https://cybersecurity-news-digest-clean.onrender.com/) · [Попробовать пример](https://cybersecurity-news-digest-clean.onrender.com/create/?demo=1)

## Возможности

- Загрузка JSON, CSV, текста и публикаций по ссылкам.
- Выбор периода по московскому времени.
- Дайджест до 4000 знаков, письмо и пост до 2000 знаков без учёта ссылок.
- Источники, пояснения к отбору и журнал обработки.
- Работа с ИИ или без него, экспорт JSON и CSV.

## Как пользоваться

1. Откройте «Создать дайджест», добавьте материалы и укажите дату и время.
2. При необходимости включите «Использовать ИИ» и нажмите «Подготовить выпуск».
3. В разделе «Результат» откройте дайджест, письмо или пост. Источники и журнал доступны в соседних вкладках.

## Запуск

Требования: Python 3.12, Node.js 22 и Corepack/pnpm. Команды выполняются из корня проекта.

На Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start.ps1 -Rebuild
```

Скрипт установит зависимости и соберёт приложение. Откройте [localhost:8000](http://127.0.0.1:8000). Для повторного запуска уберите `-Rebuild`; для остановки нажмите Ctrl+C.

Через Docker:

```sh
docker compose up --build
```

Приложение доступно на [localhost:8000](http://localhost:8000).

## Настройка ИИ

Для работы с моделью задайте в окружении сервера `LLM_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL`. Без этих настроек доступна обработка исходных материалов и учебный пример. Ключ хранится только на сервере и не добавляется в Git.

Примеры переменных находятся в [.env.example](.env.example). Подробности запуска и публикации: [docs/deployment.md](docs/deployment.md).
