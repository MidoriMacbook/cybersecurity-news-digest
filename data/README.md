# Синтетические наборы

Все тексты и ссылки `example.org` в `demo/` вымышлены для проверки поведения. Они не являются реальными новостями. Контрольное время: `2026-10-14T18:00:00+03:00`.

`sample_news.json` содержит шесть и более подходящих групп, перепечатку, противоречивые числа, предварительные сведения, prompt injection, старую публикацию, неизвестную и naive дату, рекламу, нерелевантный материал и отсутствующие поля. Отдельные файлы позволяют воспроизвести каждый крайний случай. `unavailable_sources.json` используется для проверки источника через preview, а не как входная статья.

Перегенерация: `.venv/Scripts/python.exe apps/api/build_fixtures.py` (Linux: `.venv/bin/python`).
