Полные статьи не переиздаются; проверяется обработка только представленных фрагментов, без обещания полноты исходной новости. Заголовки сокращены до названия темы. Даты и время взяты из RSS издателя; исходные URL сохранены.

В форме выберите JSON, загрузите массив и включите «Использовать ИИ». Контрольное время: **14.10.2026 17:00 Europe/Moscow**. Обе записи попадают в предшествующие 24 часа. Для малого прогона используйте первую запись; обычный прогон — обе записи с лимитом пяти событий. Ожидается не больше двух выбранных событий, поскольку на входе только две новости. Сохраняйте фактический режим: fallback не является успехом AI.

Ключ хранится только в Render Environment. Новость и краткая цитата — сведения источника, не независимое подтверждение фактов; результаты требуют редакционной оценки.
